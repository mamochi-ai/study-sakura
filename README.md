# 🌸 My Study

参考書（PDF）を左に、ノートを右に並べて勉強するためのノートアプリです。
本棚から参考書とバインダーを選んで、勉強机に広げるイメージで使います。

## iPad で使う

**→ [docs/ipad.md](docs/ipad.md)**（公開方法・ホーム画面への追加・動作チェックリスト）

PWA なので、ホーム画面に追加すればオフラインでも使えます。PC は不要です。

## 開発用（PC がある場合）

```bash
npm install
npm run dev      # http://localhost:5173 を開く
npm run build    # dist/ に本番用ファイルを出力
```

データはすべてブラウザ内（IndexedDB）に保存されます。サーバーは不要です。
大事なノートは「⋯ メニュー → バックアップを書き出す」で定期的にファイルに保存してください。

## 主な機能

### 本棚と勉強机
- **本棚**：上段に参考書（PDF）、下段にバインダーが背表紙で並びます。PDF は画面にドラッグ＆ドロップするだけで追加できます。
- **バインダー**＝ 参考書とノートのセット。科目ごとに作り、参考書は複数冊セットにできます（タブで切り替え）。
- 一度セットにすれば、ノートを開くたびに参考書を選び直す必要はありません。**参考書ごとの読んでいたページと拡大率**も覚えています。
- **勉強机**：「続きから勉強する」カードと学習記録（今日・7日間・連続日数・グラフ）が表示されます。

### 参考書（PDF）
- 連続スクロール表示、ページ移動、拡大縮小（Ctrl + ホイール / Ctrl + = / −）、幅に合わせる
- 目次（PDF のしおり情報）、🔖 しおり、全文検索
- **✂ 切り取り**：ドラッグした範囲を高解像度の画像としてノートに貼り付け（出典ページへのリンク付き）
- **文字を選択 → ❝ ノートに引用**：引用ブロックとして出典ページ付きで挿入
- **📖 p.〇 を参照**：今のページへのリンクをノートに挿入。ノート内のリンクをクリックすると参考書がそのページへ移動

### ノート
- 見出し・太字・斜体・下線・取り消し線・文字色・**マーカー（5色）**・箇条書き・番号付き・チェックリスト・引用・コード・表・画像（貼り付け / ドロップ）・リンク・**数式（KaTeX）**・上付き / 下付き・文字揃え
- `/` で開く**スラッシュメニュー**（日本語入力中の「／」でも OK）、Markdown 風の入力（`# ` `- ` `1. ` `> ` など）
- 文字を選ぶと出る**ミニツールバー**でマーカーをすばやく引ける
- **🟥 暗記シート**：赤字や選んだ色のマーカーを隠して暗記チェック（手書きノートでも使える）
- ノートはバインダーのインデックスのような横タブで切り替え。☰ から一覧（検索・並べ替え・複製・名前変更）
- ノートは自動保存
- ノートを切り替えると、**そのノートで最後に見ていた参考書のページ**が自動で開きます（設定でオフ可）
- HTML 書き出し、印刷 / PDF 保存（ノート部分だけを印刷）

### 手書きノート（Apple Pencil）
- ノート上部の「＋」から作成。Apple Pencil で書き、指でスクロール（設定で指でも書ける）
- ペン（筆圧対応）・マーカー・消しゴム（線ごと / なぞった部分だけ）、色と太さ、元に戻す / やり直す
- PDF の切り取り・引用・ページリンクを貼って、✋ で移動・拡大縮小
- 筆跡は線のデータとして保存。画面の幅が変わっても変形しない
- 用紙：無地・横罫線・方眼・ドット（テキストノートでも選べます）

### 復習マーク
- ノートの分からないところに 🚩 を付け、状態（未理解・復習中・理解済み）とメモを管理
- 「🚩 復習」一覧から絞り込み、タップでそのノート・参考書のページへ移動

### 集中のための機能
- 学習時間の自動記録（バインダーを開いて操作している間だけ。5分操作がなければ一時停止）
- 🍅 ポモドーロタイマー（時間は設定で変更可、終了時に音と通知）
- 表示切り替え：参考書だけ / 並べて / ノートだけ（Alt + 1 / 2 / 3）、分割バーはドラッグで調整（バインダーごとに記憶）
- ライト / ダークテーマ、ノートの文字サイズ変更

### iPad 対応
- PWA（ホーム画面に追加・オフライン起動・更新は確認してから適用）
- PDF の 2 本指ピンチで拡大縮小、長押しで選択した文字をノートに引用
- 指で押しやすいボタンの大きさ、セーフエリア対応

## ショートカット

| 操作 | キー |
| --- | --- |
| 表示中ページへのリンクを挿入 | Ctrl + Shift + P |
| 参考書だけ / 並べる / ノートだけ | Alt + 1 / 2 / 3 |
| 前 / 次のページ（参考書側にフォーカス時） | ← / →、PageUp / PageDown |
| 拡大 / 縮小 | Ctrl + = / Ctrl + −、Ctrl + ホイール |
| 参考書内を検索 | Ctrl + F（参考書側にフォーカス時） |
| 切り取りモード終了 | Esc |

## 技術構成

- Vite + React + TypeScript
- PDF 表示：pdf.js（日本語 PDF 用の CMap を同梱）
- エディタ：TipTap（ProseMirror）、数式：KaTeX
- 保存：IndexedDB（Dexie）

```
src/
  db.ts                  データモデル（参考書・バインダー・ノート・しおり・学習記録）
  views/DeskView.tsx     本棚と勉強机
  views/StudyView.tsx    参考書とノートの分割画面
  views/studyBus.ts      PDF 側とノート側の連携
  components/PdfPane.tsx / PdfViewer.tsx   参考書ビューア
  components/NoteEditor.tsx / NoteList.tsx ノート
  editor/                TipTap 拡張（ページ参照・数式・スラッシュメニュー）
```

## テスト

```
npm test              # 単体テスト（Vitest。IndexedDB は fake-indexeddb）
npx playwright test   # 画面操作のテスト（ビルドして iPad と同じ画面の大きさで確認）
```

GitHub に push / プルリクエストを作ると、`.github/workflows/test.yml` で型チェック・単体テスト・画面操作のテストが自動で動きます。
iPad の Safari（WebKit）での確認は、実機のチェックリスト `docs/ipad.md` で行います。
