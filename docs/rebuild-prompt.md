# My Study を作り直すためのプロンプト（完成形）

このリポジトリの完成形（2026-10-18 時点）を、Claude Code に 1 回の指示で作らせるためのプロンプト。
下の「プロンプト」の枠の中を、そのまま Claude Code（claude.ai/code など、GitHub のリポジトリにつないだもの）に貼る。

- ペット機能を作るときは、画像素材（PNG 連番・部屋の背景と家具）も一緒に渡す。素材が無いと仮の表示（🐾）で作られる
- iPad 実機の確認は人が行う。終わったら `docs/ipad.md` のチェックリストを実機で試し、気になった点を伝えて直してもらう
- AI の出力は毎回少しずつ変わるので、まったく同じ見た目・動きになるとは限らない

## プロンプト

```
あなたは iPad 向け Web アプリ（PWA）に詳しいエンジニアです。
以下の仕様で、勉強用ノートアプリ「My Study」を最後まで作ってください。
途中で質問せず、仕様に書いていないことは「iPad＋Apple Pencil で使いやすい方」を選んで進め、決めたことは docs/ に書いてください。

============================================================
0. 前提
============================================================
- 利用者は iPad＋Apple Pencil だけを使う（PC は使わない）。横向きが中心（縦向き・狭い画面でも崩れない）
- Safari で動く PWA。ホーム画面に追加して使う。オフラインで全機能が動く
- GitHub Pages で無料公開（https://<user>.github.io/<repo>/ のパスで動くよう BASE_PATH を設定）
- サーバー・有料サービス・外部 API・ログインは使わない。データは端末の IndexedDB にだけ保存
- 画面の文言・メッセージ・ドキュメントはすべて日本語。説明はやさしい言葉で
- 構成：Vite + React 18 + TypeScript、pdf.js（pdfjs-dist。日本語 CMap と標準フォントを同梱）、
  TipTap 2（テキストノート）、KaTeX（数式）、Dexie（IndexedDB）、vite-plugin-pwa
- アプリ名は「My Study」。IndexedDB の名前は一度決めたら変えない

============================================================
1. 本棚（最初の画面）
============================================================
- 上部：アプリ名、「🐾 ペットの部屋」「📕 参考書を追加」「＋ 新しいバインダー」、「⋯」メニュー
  （⋯ の中：💾 バックアップを書き出す（参考書も）／📝 ノートだけ書き出す（軽い）／📂 バックアップから復元／⚙ 設定）
- 本棚の上段に参考書（PDF）の背表紙、下段にバインダーの背表紙が並ぶ（木の本棚の見た目）
  ・背表紙の高さはページ数などで少しずつ変える。背表紙の文字は縦書き
  ・空のときは「タップして参考書（PDF）を追加」「バインダー＝参考書とノートのセット」の案内
  ・バインダーの右上に常に ✎（編集）ボタン
- 下に「勉強机」：「続きから勉強する」（最近開いたバインダー 3 つ）と「学習記録」（今日・7 日間・連続日数、直近 7 日の棒グラフ）
- 参考書をタップ：名前・色の変更、削除（「ノートの中のこの参考書へのリンクは開けなくなります」と確認）
- バインダーの作成・編集：名前、色（8 色）、セットにする参考書（表紙のサムネイル付きで複数選べる、ここから PDF も追加できる）、削除
- パソコンでは PDF のドラッグ＆ドロップでも追加できる
- PDF を追加する前に navigator.storage.estimate() で空き容量を確かめ、足りなければ案内して追加しない

============================================================
2. 勉強画面（バインダーを開いたところ）
============================================================
- 上部バー：← 本棚、バインダー名（押すと編集）、表示切り替え（📖 参考書だけ／📖│📝 並べて／📝 ノートだけ。Alt+1/2/3）、
  🚩 復習（件数バッジ）、小さなペット、⏱ 今日の学習時間、🍅 ポモドーロ（▶・リセット、終わったら音）、⚙ 設定
  上部バーの色の線はバインダーの色
- 左に参考書、右にノート。中央の仕切りをドラッグして幅を変える（ダブルクリックで半分ずつ）。幅はバインダーごとに保存
  ・仕切りは見た目より広く掴めるようにする。ただし掴む範囲はノート側にだけ広げる（PDF のスクロールバーに重ねない）
  ・指でもペンでもマウスでも動かせる（pointer capture）
- 学習時間はバインダーを開いている間を自動で数える（5 分操作がなければ止める）。30 秒ごとと閉じるときに保存

------------------------------------------------------------
2-1. 参考書（PDF）側
------------------------------------------------------------
- 上部：参考書のタブ（複数入れたら切り替え、＋で追加・入れ替え）
- ツールバー：☰（目次・しおり・検索のサイドバー）、‹ ページ番号 / 総ページ ›、− 倍率 ＋（「幅」に合わせる／100% を切り替え）、
  ✂（範囲を切り取ってノートに貼る）、📖p.N（今のページへのリンクをノートに入れる）、しおり（挟む／外す）
- ページは縦スクロールで表示。文字は選択できる（テキストレイヤー）
- 2 本指のピンチで拡大縮小（指を離したら描き直す。途中は見た目だけ拡大）。ピンチは PDF の上だけで効く
- PDF の中のリンク（目次の項目など）を押すとそのページへ飛び、「↩ p.N に戻る」ボタンが出る
- サイドバー：目次（PDF のしおり）／しおり（自分で挟んだもの。p.N 表示、✕ で外す）／検索（Enter。初回は「○ / ○ ページを読み込み中」を表示。結果は前後の文字と強調付き）
- 文字を選ぶと「❝ ノートに引用」が出る。押すと引用（出典のページリンク付き）として今のノートに入る
- ✂ を押して範囲をなぞると、その部分を画像にして今のノートに貼る（出典のページリンク付き）。Esc で終了
- 参考書ごと・バインダーごとに、最後に見ていたページと倍率を覚える
- ノートを切り替えたら、そのノートで最後に見ていた参考書のページを開く（設定でオフにできる）
- PDF が開けないとき：「参考書が見つかりません（削除された可能性）」「参考書をまだ読み込めませんでした＋[もう一度読み込む]」、
  それ以外は「iPadOS 17.4 より古いと開けないことがあります。更新してください」と案内

------------------------------------------------------------
2-2. ノート側
------------------------------------------------------------
- 上部にノートのタブ（📝 テキスト／✏️ 手書き）。左に ☰（ノート一覧・検索の引き出し）、右に ＋（新しいノート：テキスト／手書き）
  ・タブは長押し（約 0.35 秒）してから左右に動かすと並べ替え（入る位置に線を表示）。長押し前に動かしたら普通にスクロール
  ・マウスはそのままドラッグで並べ替え。順番は保存
  ・選んだタブが見えるよう、タブ列だけを横スクロール（scrollIntoView は使わない）
- ノート一覧の引き出し：ノートの検索（本文も）、ノートごとのメニュー（名前を変更・複製・↑↓移動・削除）
- 下部：文字数と「保存済み・時刻／編集中…／保存中…／保存できませんでした（やり直し中）」

【テキストノート】
- ツールバー：↶ ↷、段落スタイル（本文・見出し 1〜3）、B I U S、🖍 マーカー・文字色、•≡ 1≡ ☑ ❝、＋（挿入）、
  ☰ 用紙、Aa（その他の書式：配置・上付き/下付き・区切り線・書式をクリア）、🚩 復習マーク、暗記シート（🟥 と ▾ 隠すものを選ぶ）
- 「/」で挿入メニュー：見出し 1〜3、箇条書き、番号付きリスト、チェックリスト、引用、コード、表、区切り線、
  数式（文中）、数式ブロック（KaTeX、LaTeX で入力・Ctrl+Enter で確定）、画像、復習マーク、今のページを参照
- 表の編集（行・列の追加と削除、結合・分割、見出し行）。画像は大きさ変更と「🗑 削除」
- ページへのリンク（📖 書名 p.N）を押すと左の参考書がそのページを開く
- 画像の貼り付け・ドロップ対応。HTML として書き出し（iPad は共有シート。ファイル名から / \ : * ? " < > | を除く）
- 日本語なので自動修正・自動大文字化・スペルチェックは止める（lang="ja"）。日本語入力の変換中の Enter で誤動作しない
- 文字サイズは設定で変える（テキストノートだけ）。罫線の間隔も文字サイズに合わせる

【手書きノート】
- 用紙は横幅を 1000 とした座標で保存し、ノート側の幅に合わせて拡大縮小して描く（仕切りを動かしても筆跡が変形しない）。
  縦は書くほど伸びる。大きな用紙はタイルに分けて描き、端末の上限を超えないようにする
- ツールバー：↶ ↷、✒️ ペン、🖍 マーカー（半透明）、⌫ 消しゴム（もう一度押すと「線ごと／なぞった部分だけ」を切り替え）、
  ✋ 選択（貼った画像などを動かす・右下の丸で拡大縮小・✕ で削除。選んだときは上に説明の帯）、● 色と太さ、🚩 復習マーク、☰ 用紙、暗記シート
- タイトルはボタン表示（押すと名前を変更）。文字入力欄を用紙の近くに置かない（スクリブル対策）
- Apple Pencil で書く。筆圧で太さが変わる。getCoalescedEvents で細かく拾う。書き始めの小さな動きでも線が途切れない
- 指で用紙をなでるとスクロール（線は書かない）。慣性スクロールあり。1 本指の短いタップは選択などの操作に使う
- PDF から ✂ で切り取った画像・❝ 引用・📖 ページリンクは、手書きノートにも貼れる（貼った位置に配置、あとから動かせる）
- 元に戻す・やり直すは線の追加・削除、画像の追加・移動・削除をまとめて扱う
- ノートのピンチ拡大はしない（書くときの邪魔になるため）

2-3. 復習・暗記
------------------------------------------------------------
- 🚩 復習マーク：押してから付けたい場所を選ぶ（テキストは文中、手書きは用紙の位置）。メモを入れる
- 状態は 未理解／復習中／理解済み。上部の「🚩 復習」で一覧（状態で絞り込み、件数バッジは未完了の数）
- 一覧の項目を押すと、そのノート・その位置・付けたときの参考書のページへ移動。状態の変更・削除ができる
- 暗記シート：赤ペン（赤・オレンジ）の文字・線と、選んだ色のマーカー（黄・ピンク・緑・青・オレンジ。既定は黄と緑）を隠す。
  隠れたところをタップすると見え、もう一度で隠れる。テキストノートでも手書きノートでも使える

============================================================
3. iPad の操作で必ず守ること（実機で問題になった点）
============================================================
- 手のひら対策：右手でペンを持ち、小指の付け根（手のひらの横）を画面に置いたまま書く使い方を前提にする。
  手のひらの大きさで判定しない（指のスクロールまで止まる）。Pencil が触れている間と離してから 0.5 秒は、指の操作をすべて無視し、
  その間に始まった指は、指が全部離れるまで無視する。手のひらで少し動いたスクロールは元に戻す
- 2 本指タップで元に戻す・3 本指タップでやり直すは付けない（手を置いただけで誤作動する）。2 本以上の指が触れた操作はタップとして扱わない
- スクリブル（手書きの活字変換）や長押しメニューが手書きノートで動かないよう、用紙の touchstart を preventDefault する
- 文字の長押し選択・コピーのメニューが勝手に出ないよう、入力欄・テキストノートの本文・PDF の文字以外は user-select: none、-webkit-touch-callout: none
- scrollIntoView を使わない（ページ全体がずれて上部が隠れる）。スクロールはその要素の scrollTop/scrollLeft で行い、
  文字入力中以外にページ全体がずれたら元の位置に戻す
- 画面全体のピンチ拡大は既定で止める（gesturestart を preventDefault）。設定「画面全体を 2 本指で拡大できるようにする」でオンにできる
- Pencil でツールバーのボタンを押しても線や文字入力にならない
- PDF の中身は IndexedDB に Blob ではなく ArrayBuffer で、参考書の一覧とは別の表に保存する。
  Safari では保存した Blob を同じ起動中に 2 回目に読むと NotFoundError になる。ファイル選択で取り込んだ File を指したまま保存しない。
  以前の形式（Blob）で保存されたものは、最初に読めたときに新しい形式に移す。読めなければ少し待って読み直す
- 開いておく PDF は 2 冊まで。バインダーを閉じたら解放する。表紙のサムネイルは 1 冊ずつ描いて、すぐ閉じる
- ホーム画面のアプリではダウンロードが効かないことがあるので、ファイルの保存は共有シート（navigator.share({ files })）にする。
  共有シートはタップの直後でないと開けないので、準備ができたら「保存する」ボタンをもう一度押してもらう
- navigator.storage.persist() でデータを消されにくくする

============================================================
4. 保存とバックアップ
============================================================
- 自動保存：テキストは入力から 0.6 秒後。入力のたびに本文の控えを持ち、タブ切り替え・本棚に戻る・アプリが隠れる（visibilitychange）・
  閉じるときは即保存（エディタが閉じられたあとでも控えを保存）
- 変更に通し番号を振り、最新の変更が保存されたときだけ「保存済み」にする
- 保存に失敗したら「保存できませんでした」とトーストを出し、4 秒ごとにやり直す。容量不足は分かる言葉で
- バックアップ：
  ・ノートだけ（軽い）：ノート・手書き・しおり・復習・学習記録・ペット。参考書の PDF は含まない
  ・完全版：上に加えて参考書の PDF。圧縮しない ZIP（中に data.json と books/<id>.pdf）。ファイル名は my-study-YYYYMMDD.zip
- 復元：今あるデータは消さずに合わせる。同じものは更新日時が新しい方、学習時間は多い方、ペットの累積時間・使った餌は多い方、
  解放した家具は合わせる。参考書の中身が読めないものは入れ直す。ノートだけのバックアップでは「参考書を追加し直して」と案内。
  以前の形式（PDF を Base64 で入れた JSON）も読める。新しいバージョンのファイルは「アプリを更新して」と断る
- 設定画面：テーマ（昼・夜・自動）、ポモドーロ（集中・休憩の分）、テキストノートの文字サイズ、ノート切り替えでページを開くか、
  新しいノートの用紙、画面全体の拡大の許可、保存しているデータ（参考書の冊数と容量、全体の使用量と上限のバー）
- PWA の更新：新しい版があれば「新しいバージョンがあります → 更新する」（ノートを保存してから切り替える）。
  CMap・フォント・画像も含めて全部オフライン用に保存

5. ペットの部屋
============================================================
※ 画像素材（10 種類 × 待機・歩く前後左右・食べる・空腹・寝る・遊ぶ・喜ぶ・びっくり 各 8 コマ 256×256 足元 (128,232)、
   部屋の背景 1536×1024 と家具 9 点と配置 JSON）を添付する。無ければ仮の表示で作る
- 素材は変換スクリプト（Python＋Pillow）で WebP のスプライトシート（横に 8 コマ）にし、再生設定（コマ順・1 コマの時間・ループ・
  終わったら戻る動き・ボールを含むか）は JSON で管理する。読み込めない動きは待機の絵で、それも無ければ 🐾 で仮に表示
- 種類：犬（柴犬・ゴールデンレトリバー・コーギー）、猫（サバトラ・三毛猫・ラグドール）、マーモット、鳥（セキセイインコ・オカメインコ・文鳥）
- 迎える：選ぶ画面（種類ごとに並べる、名前を付ける）。最大 5 匹、累積学習 0・10・30・60・100 時間で 1 匹ずつ。同じ種類も可
- 累積学習時間はペット用に別に記録（バインダーを消しても減らない）。初めて部屋を開いたとき、それまでの学習記録を合計して始める
- 餌：学習 10 分につき 2 個（秒単位で積み上げ）。「🍖 みんなにごはん」は餌 3 個で満腹でない全員が食べる。1 匹ずつもあげられる（餌 3 個）
- 満腹度：最初 80、ごはんで +30（上限 100）、6 時間ごとに −10（0 で止まる。死なない）。閉じていた間も減る。30 以下で空腹
- 家具：累積 0 時間 寝床・餌皿／1 ラグ／3 おもちゃ（ボール・ねずみ）／5 クッション／10 本棚／20 観葉植物／40 キャットタワー。
  一度解放したら消えない。新しく解放されたら「🎉 新しい家具が届きました」と出して、上から置かれる演出
- 部屋の画面：左に部屋、右にパネル（餌・今日／累積の学習時間・みんなにごはん、ペットのカード（満腹度のバー・🍖）、家具の一覧（✓／🔒 時間）、
  次の家具、次のお迎え）。カードを押すとメニュー（ごはん・名前を変える・ノート画面に出す）
- 部屋は 2 本指のピンチで拡大縮小（最大 3 倍）、拡大中は 1 本指でずらす（ずらしたあとの指離しはタップにしない）。右下に ＋ − ⤢
- 行動（状態マシン：idle・walk・eat・happy・hungry・sleep・play・interact・surprise。許されない移り方はしない）：
  歩き回る、寝床で眠る、クッションに座る・眠る、キャットタワーの低い台に乗る、ボールで遊ぶ（遊ぶ間は床のボールを隠す）、
  ねずみのそばで喜ぶ、空腹なら餌皿の前で待つ、タップでびっくり、ごはんで餌皿のまわりの別々の場所に並んで食べる（餌皿を隠さない）
- 歩く：床の範囲と家具の足元を避ける地図（24px のマス目で A*、見通しのきく点を飛ばす）。家具の上り下りだけはまっすぐ移る
- 複数匹：体を楕円（横 125・奥行き 42）とし、止まっている子と歩いている子の行き先をよける。ふさがれたら待つ／回り道、4 秒で通り抜ける。
  止まったときに重なっていたら離れる。同じ家具・おもちゃを同時に使わない。仲間のとなりで休む
- 仲間との交流（2 匹とも空いているときだけ、両方が着いてから同時に始める）：向き合って挨拶、並んで座る、並んで眠る、
  1 匹がボールで遊び相手は喜ぶ、追いかけっこ（最後に向き合う）。タップ・ごはんで中断
- 奥行き：足元の高さと家具の接地位置で重なり順を決める。家具に乗っているときは家具の上に描く
- 描画：requestAnimationFrame 1 本。値が変わったときだけ DOM に書く。画面が隠れたら止める
- ノート画面の上のバーに小さなペット（ノート画面に出すと選んだ子。ゆっくり呼吸するだけ。空腹なら 🍖）。押すと部屋、「← 戻る」でバインダーへ

6. 進め方・品質
============================================================
- 最初に構成・データの形・作る順番を docs/ に書いてから作る
- 機能のまとまりごとにコミットし、各段階で次を通してから次へ進む：
```
