ノート機能とは独立したモジュール（`src/pets/`）として作る。既存のノート・PDF・復習のデータは変更しない。

## データモデル

```ts
interface Pet {         // pets テーブル
  id: string;
  species: string;      // 'shiba' など
  name: string;
  fullness: number;     // fullnessAt 時点の満腹度 0〜100
  fullnessAt: number;   // 6 時間ごとに 10 減る計算の起点
  adoptedAt: number;    // お迎え履歴
  order: number;
}
interface PetWorld {    // petWorld テーブル（1 件、id = 'world'）
  studySeconds: number; // ペット用の累積学習時間（バインダーを消しても減らない）
  foodSpent: number;    // 餌の所持数 = floor(累積 / 10 分) × 2 − foodSpent
  unlocked: string[];   // 解放済みの家具（永久に保持）
  miniPetId?: string;   // ノート画面に出すペット
  createdAt: number;
  updatedAt: number;    // 最終更新日時
}
```

- 部屋を初めて開いたとき、これまでの `sessions` を合計して `studySeconds` の初期値にする
- 満腹度は保存した値と時刻から計算するので、アプリを閉じていた間も減る
- 最初の満腹度は 80、30 以下で「空腹」

## アニメーションの方式

- 素材：1 コマ 256×256、足元は (128, 232)。各動き 8 コマ
- 1 つの動きを 1 枚の WebP（横 8 コマ）にまとめ、CSS の `background-position` でコマを切り替える
- 再生設定（コマ順・1 コマの時間・ループ・終わったら戻る動き）は `assets.json` で管理。素材を差し替えるときは、変換スクリプトを再実行する
- 素材が無い動きは、待機の静止画で代用する
- Phase B 以降：部屋の画面だけで `requestAnimationFrame` を 1 本回し、全ペットの位置とコマを更新する。画面が隠れたら止める
- 奥行き：家具とペットの重なり順を、床に接している位置（`groundY` / 足元）で決める
- ノート画面の小さなペットは控えめにする（Pencil の描画を邪魔しないよう、まずは静止画）

## 画像素材の一覧

| 種類 | 待機 | 歩く（前・後・左・右） | 食べる | 空腹 | 寝る | 遊ぶ | 喜ぶ | びっくり |
|---|---|---|---|---|---|---|---|---|
| 柴犬・ゴールデン・コーギー | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ |
| サバトラ・三毛猫・ラグドール | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ |
| マーモット | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ |
| セキセイ・オカメ・文鳥 | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ |

- 待機は静止画 1 枚（まばたきなどは無し）
- 交流専用の素材は無い。今ある動きの組み合わせで表現する
- 「遊ぶ」の絵にはボールが描かれているので、遊んでいる間は部屋のボールを隠す
- 部屋：背景 1 枚（窓つき）、家具 9 点（寝床・餌皿・ラグ・ボール・ねずみ・クッション・本棚・観葉植物・キャットタワー）。配置は第 4 段階に固定

## 行動（Phase B）

- 状態：idle・walk・eat・happy・hungry・sleep・play・interact・surprise
- 状態マシン（`brain.ts` の `NEXT`）にない移り方はしない。例：食べている間は眠らない、寝ている間は歩かない（起きて寝床から出てから）
- 待機が終わると次の行動を決める：歩き回る（50%）／寝床で眠る（15%）／その場で待機
- 満腹度 30 以下なら、餌皿の前で「空腹」の動き（40 秒に 1 回まで）
- 移動：床を 24px のマス目に分け、家具の足元をふさいだ地図で A* を使い、見通しのきく点を飛ばしてなめらかにする
- 寝床に入るときと出るときだけは、地図の外（寝床の上）をまっすぐ歩く
- 奥行き：ペットの足元の高さと、家具の `groundY` を比べて重なり順を決める。寝床の中では寝床の上に描く

## 餌と満腹度（Phase C）

- 餌の所持数 = floor(累積学習秒 / 600) × 2 − 使った数。学習時間は 1 秒単位で積み上がるので、端数も無駄にならない
- 「みんなにごはん」：餌 3 個で、満腹（100）でない全員の満腹度を +30（上限 100）
- 1 匹ずつ：ペットの横の 🍖、またはペットのメニューから。餌 3 個でその子だけ
- 満腹度は保存した値と時刻から計算する。ごはんで増やすときも、6 時間ごとに減る周期はずらさない
- 部屋を開いている間も、1 分ごとに満腹度の表示を更新する
- 餌皿のまわりの 5 か所に分かれて食べる（重ならないように）

## 家具を使う動き（Phase D）

- 乗れる家具：寝床（眠る）、クッション（座る・眠る）、キャットタワーの低い台（座る）。前まで歩いてから、家具の上へまっすぐ移る。乗っている間は家具の上に描く
- おもちゃ：ボールの上で「遊ぶ」（絵にボールが描かれているので、床のボールは隠す）。ねずみのそばで「喜ぶ」
- 使っている家具は World.taken に記録し、同時に 2 匹では使わない（Phase E の準備）
- 家具の解放は `petWorld.unlocked` に保存し、新しく解放されたものだけ部屋を開いたときに知らせる（初めて部屋を作ったときは知らせない）

## 複数匹（Phase E）

- 各ペットは別々の満腹度と行動状態を持つ（`pets` テーブル 1 行と、`PetActor` 1 つ）
- 体の大きさを楕円（横 125・奥行き 42）で表し、止まっている子の楕円には入らない
  - 道順を探すとき、止まっている子の位置と、歩いている子の行き先をよける
  - 歩いている途中で前をふさがれたら：相手が歩いていれば少し待つ。止まっている相手なら回り道。4 秒たっても進めなければ、すれ違う
  - 行き先を決めるとき、ほかの子から離れた場所を選ぶ。止まったときに重なっていたら少し離れる
- 「仲間の近くで休む」：床で休んでいる子のとなりへ行って、待機か睡眠
- 寝床・クッション・キャットタワー・おもちゃは、使っている子がいる間はほかの子は選ばない
- 描画は requestAnimationFrame 1 本。値が変わったときだけ DOM に書く

## 仲間との交流（Phase F）

- `Duo`（`brain.ts`）：2 匹の交流。種類は greet（挨拶）・sit（並んで座る）・sleep（一緒に寝る）・ball（おもちゃで遊ぶ）・chase（追いかけっこ）
- 誘える相手：床で待機中か歩き回っている途中、家具に乗っていない、お腹がすいていない、10 秒以内に交流していない
- 2 匹の場所を先に決める（横に 180 離して並ぶ。ほかの子の場所・行き先と重ならないところ）。両方が着いてから同時に始める
- 始めるとき相手のほうを向く（挨拶と追いかけっこの終わりは、歩く絵の 1 コマ目で 1 秒向き合ってから喜ぶ）
- 追いかけっこ：誘った子が部屋の 3 か所を速足で回り、相手は 160 以上の間をあけて追う。止まったらとなりに並ぶ
- 20 秒以内にそろわなければやめる。タップ・ごはんでも、始まる前なら 2 匹ともやめる
- 交流の相手同士はよける対象から外す（となりに並べるように）
- 自動テスト用に、URL に `?petdebug` を付けると `window.__petWorld` から状態を読める

## 実装順序

| Phase | 内容 |
|---|---|
| A | ペット選択、部屋の表示（背景・解放済みの家具・ペットの静止画）、情報パネル、勉強画面の小さなペット、保存とバックアップ |
| B | 1 匹の行動：待機・歩く・食べる・寝る（状態マシンと移動） |
| C | 餌と学習時間の連携、満腹度、ごはんをあげる（個別・みんなに） |
| D | 家具の解放の演出と、家具を使う行動（クッションに座る・寝床で寝る） |
| E | 複数匹の自律行動と、ぶつからない移動 |
| F | 仲間との交流 |
| G | アニメーションの調整と iPad 実機テスト |
